# Supplied runner and logging prototypes

These are archival reference copies of the files supplied for refactoring.
They are **not imported or packaged** by LagaPy; the supported APIs live in
`src/lagapy/logging.py` and `src/lagapy/solver/`.

Machine-specific Windows paths in `RunFile1.py` and `RunFile2.py` were replaced
with generic examples to avoid publishing local directory information. The
`run.py` and `__init__.py` files are intentionally left as originally supplied
(including their stale imports) to document their original state.

Do not run the archival scripts: use the updated example in
`examples/run_lagamine.py` instead.
