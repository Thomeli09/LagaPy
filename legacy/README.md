# Original prototypes — preserved unchanged

These files are copied verbatim from the provided ZIP (July/October 2026)
and are **not** part of the installable `lagapy` package. They document the
first ideas for `Lagamine`, `LagGeneric`, `LagMesh`, `LagLaw`, `LagCond`,
`LagSolver` and `LagPri`.

Several prototypes contain incomplete path handling and other placeholder
behaviour. They are kept for reference and should not be imported as a
functional FE library. Their design intent is reflected in
[`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md).

`Architecture.original.md` contains the original architectural notes.
